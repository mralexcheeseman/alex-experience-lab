# Alex Cheeseman — In person

Private editorial portfolio prototype. Static, dependency-free HTML, CSS and JavaScript.

## Direction
Human presence through a real portrait, published conversation, concise experience and independent projects. Original layout; no Lab specimen code reused or promoted. Proposed first-person copy requires Alex's editorial review. No invented outcomes, client endorsements or success metrics.

- `dist/assets/alex-interview.jpg`: official YouTube thumbnail for the ExchangeWire 2023 interview, https://img.youtube.com/vi/mVeYbjFuyvE/maxresdefault.jpg

Public-source media used for private review; public reuse rights not established. A new approved portrait and cleared original media should replace archival media before a public release. Project cover graphics are typographic studies, explicitly labelled. No AI-generated likeness.

## Verification
- JavaScript syntax checked with node --check.
- HTML checked for unique IDs, resolving internal anchors, local image files, image alt text and valid link schemes.
- Three images inspected/checked as local assets; portrait and interview visually inspected.
- Responsive CSS includes narrow-screen composition, 44px navigation/control targets, focus states and reduced motion. These are implemented, not browser-certified.
- Browser QA not available: the required control-browser capability is absent. No rendered visual, interaction, accessibility or performance pass is claimed.
- External social/project links open their original destinations. No form submission or email sending occurs.

## Known content gaps
Three cleared career case studies with Alex's exact role and outcomes; current professional photography; approved personal positioning. Existing evidence demonstrates experience, not every requirement of the VML vacancy. Synthetic research, trade/shopper and whole-brand strategy ownership remain unproven here.

## Source
Sites maintains the deployable source Git repository. The Alex Experience Lab review branch records this application and mirrors the HTML/CSS/JS. The Lab's own programme and homepage are unchanged.

## Reviewing this GitHub snapshot
The HTML/CSS/JS files mirror the deployed dist files. Run `python3 download-assets.py` in this folder to restore the three public-source media files, then serve this directory with any static server. Binary media is retained in the private Sites source repository.
