# Design DNA v1 — Provisional Hypothesis

Status: **assistant hypothesis; awaiting Alex validation.**

This file is intentionally provisional. It is derived from research into ORYZO AI, The Symphony of Vines, Shopify Editions Spring ’26, Bruno Simon and Every Neuron — not from Alex's completed preference workbook.

## Hypothesis A — One dominant idea
A page/scene should usually have one memorable interaction or visual idea, not a stack of competing effects.

## Hypothesis B — Restraint creates contrast
The high-impact moment needs quieter typography, colour, motion and UI around it.

## Hypothesis C — Interaction should have a job
Prefer interactions that:
- explain
- reveal
- navigate
- manipulate
- organise
- create a meaningful emotional response

Avoid motion whose only explanation is "it looks advanced."

## Hypothesis D — Stable grammar, controlled variation
Different sections can behave differently when:
- navigation remains understandable
- transition rules remain consistent
- typography/system tokens preserve continuity

## Hypothesis E — Spectacle must hand back to utility
Immersion should not trap the user.

Good patterns include:
- explorer after guided story
- functional product UI after cinematic hero
- map/respawn/settings around unconventional navigation
- hierarchy that allows fast scanning after visual impact

## Hypothesis F — Recovery is part of interaction design
The more experimental the interaction, the more important:
- reset
- skip
- map
- fallback
- reduced motion
- quality controls
- mobile alternative

## Hypothesis G — Visual material should be semantically earned
Best:
- real product as hero
- real dataset as geometry
- geography as feature journey
- physical behaviour as explanation

Weak:
- particles because particles
- 3D object because 3D
- shaders with no relationship to subject

## Hypothesis H — Density needs hierarchy, not more cards
Use:
- explicit priority levels
- variable scale
- section taxonomy
- repeated patterns
- embedded product/media evidence

Avoid:
- equal-sized card grids for unequal information

# Validation questions for Alex

When reviewing the first five sites, test these hypotheses explicitly:

1. Do you prefer one dominant interaction over layered effects?
2. How much "quiet" should surround spectacular moments?
3. Do you care whether an effect has semantic meaning, or can pure visual delight justify it?
4. How unconventional can navigation become before it annoys you?
5. Do you prefer guided storytelling first or immediate free exploration?
6. Do you like clear category/system structure even inside experimental sites?
7. How much humour/personality should Alex UI permit?

# Promotion rule

Nothing in this document becomes permanent Alex UI doctrine until supported by:
