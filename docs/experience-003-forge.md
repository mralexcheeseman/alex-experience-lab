# Experience 003 — Forge

## Why this exists

Forge replaces the failed Archive direction and returns directly to the original project objective:

**curate, combine and evaluate exceptional React / motion / WebGL primitives to discover a reusable high-end visual language.**

## Core mechanic

**Select → combine → feel the result.**

The user activates up to three primitives. The live stage changes immediately. Recipes allow known-good combinations to be restored.

## V1 questions

1. Can a component audition environment itself feel premium?
2. Can three interaction primitives coexist without creating visual soup?
3. Can we make source / licence metadata visible without turning the page into documentation?
4. Can useful combinations become named recipes?
5. Which primitive abstractions deserve deeper investment?

## V1 scope

### Live stage
One authored composition.

### Specimen rail
Four initial primitives:
- Kinetic Type
- Depth Planes
- Magnetic Field
- Cursor Lens

### Combination constraint
Maximum three active primitives.

### Recipes
Three named compositions:
- Editorial Depth
- Tactile Field
- Full Tension

### Source registry
Every third-party candidate must have source and licence status before adoption.

## Visual direction

Studio instrument, not dashboard.

- warm paper
- black ink
- one cobalt accent
- industrial/editorial precision
- physical specimen cards
- strong typography
- restrained motion

Avoid:
- dark cinematic trope
- glass panels
- generic SaaS dashboard UI
- neon gradients
- gratuitous particles
- "AI-looking" cards
- a component grid as the main experience

## Acceptance test

Forge v1 fails if:
- the stage feels like a component demo rather than a designed composition
- primitives cannot be clearly turned on/off
- combinations become visually chaotic
- the source / licence story is unclear
- the page does not teach us anything reusable
- mobile is merely a squeezed desktop version

## Promotion rule

Nothing in Forge v1 is automatically Alex UI.

A primitive may become a candidate only after:
- visual review
- mobile review
- reduced motion review
- performance review
- licensing review
- evidence it is useful in more than one composition
