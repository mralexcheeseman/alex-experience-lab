# Cutting-Edge Website Cohort — 20 References

Date: 2026-09-24

Purpose:
Create a fixed inspiration cohort for Alex Experience Lab. We will deconstruct these sites, identify the interaction and visual mechanics we actually like, then rebuild selected principles as standalone specimens before combining anything.

This is not a "best websites" ranking. The cohort is intentionally varied so each reference teaches a different lesson.

## 01 — Léo Parpeix — Portfolio 2026
URL: https://leoparpeix.com/

Primary lesson:
World-building as portfolio architecture.

What to inspect:
- each project page as a distinct 3D world
- visual continuity across changing environments
- relationship between 3D environment and navigation
- use of sound
- how quickly the visitor understands where they are

Candidate rebuild:
A small reusable "world switcher" specimen: one object remains constant while material, environment and camera language change.

# Deconstruction framework

Every site should be reviewed against the same fields:

1. **First 5 seconds**
   - what do you notice?
   - what do you understand?
   - what makes you want to interact?

2. **Core mechanic**
   - what is the one interaction you remember?

3. **Visual system**
   - typography
   - colour
   - image/3D treatment
   - spacing
   - composition

4. **Motion grammar**
   - entrance
   - hover
   - scroll
   - page transition
   - idle/ambient motion

5. **Navigation**
   - conventional or bespoke?
   - how is orientation preserved?
   - mobile behaviour?

6. **3D / shader role**
   - explanation
   - navigation
   - atmosphere
   - product visualisation
   - spectacle
   - unnecessary?

7. **Sound**
   - absent / optional / essential
   - what does it add?

8. **Performance strategy**
   - lazy loading
   - quality scaling
   - asset density
   - mobile fallback
   - reduced motion

9. **What we like**
   - explicit user approval only

10. **What we do not like**
    - equally important; prevents accidental copying

11. **Rebuild candidate**
    - smallest useful interaction/visual principle we can recreate as a standalone specimen

12. **Combination potential**
    - leave blank until we have completed the first deconstruction pass across all 20

# Rule

Do not rebuild whole sites.

Rebuild the smallest interaction, visual treatment or system that creates the value we admire.

Do not combine candidates until the first deconstruction pass is complete.
