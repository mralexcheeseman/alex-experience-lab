## Provisional principles supported by this reference

These are grounded in the current implementation plus Alex's explicit positive reaction:

1. **Experience before interface**
   - The first screen behaves like an encounter, not a dashboard or landing-page template.

2. **Editorial typography can carry atmosphere**
   - Type is structural and emotional, not decoration added after effects.

3. **One immersive canvas can do more than many UI effects**
   - The visual field is continuous and dominant.

4. **Minimal interface chrome**
   - The opening avoids visible card systems, menus, badges and standard SaaS patterns.

5. **A deliberate threshold can be valuable**
   - `ENTER EXPERIENCE` creates a transition from arrival into exploration.

6. **Sparse copy**
   - The screen communicates a tone and proposition with very little text.
