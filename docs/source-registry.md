# Source Registry

Purpose: track component / primitive sources before they influence the Forge or `alex-ui`.

## Motion Primitives

Source: https://motion-primitives.com / https://github.com/ibelick/motion-primitives

Status: approved reference / code source.

Licence: MIT.

Use:
- motion interaction patterns
- text animation
- transitions
- small reusable motion primitives

Alex UI:
Eligible for adaptation provided the MIT licence notice is preserved where required and the result meets our own design/performance review.

## React Bits

Source: https://reactbits.dev / https://github.com/DavidHDev/react-bits

Status: approved for product experimentation; restricted for component redistribution.

Licence: MIT + Commons Clause condition.

Use:
- visual experiment reference
- shaders / cursor / text / background ideas
- direct use inside an end application where licence conditions permit

Alex UI:
Do not directly redistribute React Bits components through our own component registry. Rebuild underlying interaction principles internally if we want a distributable Alex UI primitive.

## Aceternity UI

Source: https://ui.aceternity.com

Status: discovery / app-use candidate.

Notes:
Free components are presented as copy-paste React / Next.js components. Premium items use Aceternity's own licence.

Use:
- discover interaction patterns
- audition free components in end applications where terms allow
- compare component composition ideas

Alex UI:
No direct promotion until the licence for the exact item is checked and recorded.

## 21st.dev

Source: https://21st.dev

Status: discovery layer.

Use:
- search for component ideas
- identify source libraries / authors
- benchmark variations

Alex UI:
Never assume 21st.dev itself grants reuse rights. Follow the licence of the underlying component/source.

## React Three Fiber / Three.js

Status: approved technical foundation for bespoke 3D primitives.

Use:
- authored 3D scenes
- depth / spatial interaction
- shaders / geometry experiments

Alex UI:
Promote only small, reusable abstractions with a clear product use case. Do not turn Alex UI into a generic 3D engine.
