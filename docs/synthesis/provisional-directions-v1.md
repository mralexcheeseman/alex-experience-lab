## Direction A — Artifact Signal

Combination:
- Pixel Stars
- Hero Object Framing
- narrow Sparkle Bloom

Question:
Can deliberate low-fidelity digital atmosphere make a tactile object feel more distinctive without slipping into generic "premium 3D product" styling?

Intent:
- Pixel Stars supplies character.
- Hero object supplies focus.
- Sparkles is used only as a restrained transition/accent, not a background language.

Failure mode:
Too many visual signatures compete, or the central object still reads as a generic floating product.

Route on synthesis branch:
`/synthesis/a-artifact-signal`

## Direction B — Editorial Current

Combination:
- Chapter Interaction grammar
- Editorial hierarchy
- narrow Sparkle Bloom

Question:
Can an information-dense product/editorial system gain emotional rhythm without sacrificing scanability?

Intent:
- Explicit hierarchy does the structural work.
- Chapter switching creates controlled variation.
- Sparkles adds one atmospheric accent at the hero boundary.

Failure mode:
It becomes a normal editorial grid with decorative motion stuck on top.

Route on synthesis branch:
`/synthesis/b-editorial-current`

## Direction C — Field Atlas

Combination:
- Data → Geometry
- Navigable Micro-World

Question:
Can navigation itself change information priority?

Intent:
- User physically moves through a structured visual field.
- Nearby data becomes more legible.
- Navigation and information are the same system.

Failure mode:
It becomes a generic node map or game mechanic with no reason to exist.

Route on synthesis branch:
`/synthesis/c-field-atlas`

# Review framework

For each direction:
- immediate reaction
- what feels original?
- what feels derivative/generic?
- which ingredient is carrying the experience?
- which ingredient should be removed?
- does the combination feel stronger than the parts?
- could this solve a real product/website problem?
- KEEP / MAYBE / KILL
